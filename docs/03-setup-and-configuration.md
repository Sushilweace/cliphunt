# Setup and configuration

## Requirements

- Node.js 20 or newer
- ffmpeg with libx264, libass (and typical audio codecs)
- Optional: yt-dlp (YouTube), Python 3 with `faster-whisper` and `opencv-python`
- Optional: Ollama, or Gemini / Anthropic / OpenAI API keys

## Quick start

```bash
cp .env.example .env   # fill only the keys you need
npm start              # http://localhost:3000
npm test               # smoke test (sets LLM_PROVIDER=none, mock transcription)
```

On Windows PowerShell, use `;` between commands, not `&&`.

Only one process may bind to port 3000. If you see `EADDRINUSE`, stop the existing listener before starting again.

## Free / local path

```bash
pip install faster-whisper opencv-python
# .env
TRANSCRIBE_PROVIDER=local
LLM_PROVIDER=ollama
OLLAMA_MODEL=llama3.2:3b
OLLAMA_NUM_CTX=8192
```

With a 4 GB GPU, `llama3.2:3b` is the usual fit. Larger models may spill to CPU and run slower.

## Fast highlights path (Gemini)

```bash
LLM_PROVIDER=gemini
GEMINI_API_KEY=your-key
GEMINI_MODEL=gemini-3.8-flash
```

With `LLM_PROVIDER=auto`, Gemini is preferred if a key is set, then Anthropic, then Ollama.

## Environment variables

Copy from `.env.example`. Do not commit `.env`. Important groups:

### Server

| Variable | Default | Meaning |
|---|---|---|
| `PORT` | `3000` | HTTP port |
| `DATA_DIR` | `./data` | Database and media root |
| `MAX_UPLOAD_GB` | `4` | Upload size limit |
| `MAX_DURATION_MIN` | `120` | Reject longer sources |
| `AUTO_RENDER` | `0` | `1` = render top clip after analysis |
| `ENABLE_YOUTUBE` | `1` | Allow yt-dlp ingest |
| `FONTS_DIR` | empty | Extra fonts for ASS |

### Transcription

| Variable | Notes |
|---|---|
| `TRANSCRIBE_PROVIDER` | `openai` \| `local` \| `mock` \| `none` |
| `OPENAI_API_KEY` | Whisper API + optional TTS |
| `LOCAL_WHISPER_MODEL` | e.g. `small` |

### LLM

| Variable | Notes |
|---|---|
| `LLM_PROVIDER` | `auto` \| `gemini` \| `anthropic` \| `ollama` \| `none` |
| `GEMINI_*` / `ANTHROPIC_*` / `OLLAMA_*` | Model, host, timeouts, ctx, predict |

### Token caps

| Variable | Default | Meaning |
|---|---|---|
| `MAX_PROJECT_TOKENS` | `80000` | Cap for one project’s analysis usage (`0` = off) |
| `MAX_CLIP_TOKENS` | `8000` | Cap for one post-copy / related clip call (`0` = off) |

### Tool paths (optional)

| Variable | Meaning |
|---|---|
| `FFMPEG_PATH` / `FFPROBE_PATH` / `YT_DLP_PATH` | Absolute paths if not on PATH |
| `PYTHON` | Preferred Python executable |

`server/env.js` loads `.env` only for variables that are not already set (so tests can override).

## External tools on Windows

The server searches PATH and common WinGet package folders for `ffmpeg`, `ffprobe`, and `yt-dlp`, then injects those directories into child process `PATH` so yt-dlp can merge video+audio.

Python: `server/python.js` picks an interpreter that can `import faster_whisper` (important when multiple Python installs exist).

## Music files

Drop licensed `.mp3` / `.m4a` / `.wav` / `.aac` / `.ogg` into `data/music/`. They appear in the editor Music dropdown after refresh. Built-in pads are generated by `server/music.js` if missing.
