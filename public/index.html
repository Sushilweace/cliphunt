    YouTube Account & API Settings

    Google Cloud OAuth 2.0 Credentials

    To upload and schedule to your channel, enter your OAuth Client credentials from Google Cloud Console (YouTube Data API v3 enabled).

    Quick Setup Guide
    1. Open Google Cloud Console and create a project.
    2. Go to APIs & Services > Library and enable YouTube Data API v3.
    3. Under OAuth consent screen, choose External, set User Support Email, and add scope .../auth/youtube.upload. (Add your email as a Test User).
    4. Under Credentials, create OAuth Client ID (Web application) with Authorized Redirect URI http://localhost:3000/api/youtube/callback.
    5. Paste the Client ID and Client Secret above and click Connect.
