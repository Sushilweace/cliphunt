    YouTube Account & API Settings

    Google Cloud OAuth 2.0 Credentials

    To upload and schedule to your channel, enter your OAuth Client credentials from Google Cloud Console (YouTube Data API v3 enabled).

    Quick Setup Guide
    1. Open Google Cloud Console and create a project.
    2. Go to APIs & Services > Library and enable YouTube Data API v3.
    3. Under OAuth consent screen, choose External, set User Support Email, and add scope .../auth/youtube.upload. (Add your email as a Test User).
    4. Under Credentials, create OAuth Client ID (Web application) with Authorized Redirect URI http://localhost:3000/api/youtube/callback.
    5. Paste the Client ID and Client Secret above and click Connect.

    YouTube Bot Verification (Cookies)

    Upload cookies.txt or Paste Cookie Data

    YouTube blocks automated downloads on some videos with "Sign in to confirm you're not a bot". Providing exported cookies authenticates the download.

    How to get YouTube cookies in 1 minute
    1. Install Chrome extension Get cookies.txt LOCALLY (safe, open-source).
    2. Open YouTube in that browser while logged in.
    3. Click the extension icon in your toolbar, then click Export (it downloads cookies.txt).
    4. Choose that file above and click Save Cookies!

    ⚡ Tip: Or simply switch to the "Upload a file" tab above to upload any video file directly without needing any cookies!
